# Yük İzleme

## What it does
Bu Mac'in işlemci, sıcaklık, bellek ve disk durumunu tek ekranda gösterir. Makine yavaşladığında düz bir cümleyle nedenini ve yükü tutan işlemleri (Claude oturumları, dev işleri, diğer uygulamalar) söyler. Yalnızca okur, hiçbir şeyi değiştirmez.
